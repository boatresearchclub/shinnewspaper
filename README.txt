=============================================
 ボートリサーチ倶楽部 — サーバー構成
=============================================

【フォルダ構成】
  boat_server.py              ← Flaskサーバー本体
  build_master_json.py   ← ExcelマスタをJSONに変換するスクリプト
  index.html             ← フロントエンド（ブラウザで開く）
  master_data.json       ← 変換済みマスタデータ（1699選手/24会場）
  ボートリサーチ_マスタ.xlsx  ← 元のExcelファイル（同じフォルダに置く）
  csv/                   ← 当日CSVを入れるフォルダ（自動作成）

【初回セットアップ】
  pip install flask flask-cors pandas openpyxl

【起動方法】
  python boat_server.py
  → ブラウザで http://localhost:5000 を開く

【CSVの使い方】
  - csv/ フォルダに 鳴門_2026-04-25.csv を入れると自動ロード
  - または画面にドラッグ＆ドロップ → Excelマスタで確率計算

【Excelマスタを更新したとき】
  1. ブラウザ右上の「📊 マスタ更新」ボタンをクリック
     または
  2. python build_master_json.py ボートリサーチ_マスタ.xlsx

【確率計算の仕組み（Excelマスタ版）】
  優先① 選手×コース別の実績1着率（個人データ・5走以上）
  優先② 会場別コース別1着率（鳴門の1コース=47.3%など）
  優先③ 全国平均（1C=55.5%, 2C=13.8%, ...）
  → 6艇の合計が100%になるよう正規化して表示
